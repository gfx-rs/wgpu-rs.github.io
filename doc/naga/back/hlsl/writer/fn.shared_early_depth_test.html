fn shared_early_depth_test(
    module: &Module,
    entry_points: Range<usize>,
    ty: Handle<Type>,
) -> Option<EarlyDepthTest>
Expand description

Gets the early depth test of the fragment entry points in entry_points that return ty.

Returns None if there are no such entry points or if they disagree. The semantic of a depth output is part of the definition of the struct that contains it, so a struct that is shared by entry points with different settings cannot use a conservative semantic.
