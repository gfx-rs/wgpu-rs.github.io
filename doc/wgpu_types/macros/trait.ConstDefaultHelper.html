Trait ConstDefaultHelper

pub(crate) trait ConstDefaultHelper {

}
Expand description

Default value of a type, as a const item.

This trait is not public and is used solely to help ConstDefault provide inherent const fn default()s.

Specifically, it is implemented both for wgpu-types types and std types, so that the macro ConstDefault can call it without needing to understand the type.
